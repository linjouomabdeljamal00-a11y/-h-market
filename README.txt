H MARKET — SITE E-COMMERCE STATIQUE

Fichiers :
- index.html : site principal
- style.css : design
- script.js : catalogue, panier et commande WhatsApp

PUBLICATION :
1. Téléversez les 3 fichiers sur un hébergeur statique (Netlify, Vercel, GitHub Pages, etc.).
2. Aucun serveur ou base de données n'est nécessaire pour cette version.
3. Pour modifier les produits, prix et descriptions, éditez le tableau "products" dans script.js.
4. Le numéro WhatsApp est configuré sur +237 696 195 721.

IMPORTANT : cette version envoie les commandes à WhatsApp. Elle ne gère pas encore le paiement en ligne ni un espace administrateur.
